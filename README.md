# 🍳 SmartChef — Smart Recipe Generator

SmartChef is a modern and interactive **React.js recipe generator** that helps users discover recipes based on the ingredients they already have.

The application provides a beautiful animated interface with recipe recommendations, ingredient matching, favorites, weekly meal planning, and a shopping list.

## ✨ Features

* 🥕 Smart ingredient selection
* 🤖 Ingredient-based recipe matching
* 🍝 Recipe recommendations
* 🔎 Recipe search
* 🏷️ Category filtering
* ⏱️ Cooking-time filtering
* ❤️ Favorite recipes
* 📅 Weekly meal planner
* 🛒 Shopping list
* 📊 Nutrition information
* 🌙 Dark / Light mode
* 💾 LocalStorage support
* 📱 Fully responsive design
* ✨ Smooth CSS animations
* 🎨 Modern glassmorphism UI
* 🪄 Animated recipe cards
* 🍳 Interactive recipe details modal

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/smartchef-react-recipe-generator.git
```

### 2. Open the project

```bash
cd smartchef-react-recipe-generator
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## 🎯 How It Works

### Step 1 — Select Ingredients

Choose ingredients available in your kitchen.

Example:

```text
🍅 Tomato
🧅 Onion
🥚 Egg
🍚 Rice
```

### Step 2 — Smart Matching

SmartChef compares your selected ingredients with recipe ingredients and calculates a matching percentage.

```text
Ingredients Available
        ↓
Recipe Database
        ↓
Ingredient Matching
        ↓
Match Percentage
        ↓
Recommended Recipes
```

### Step 3 — Explore Recipes

View recipe details including:

* Cooking time
* Calories
* Difficulty
* Rating
* Ingredients
* Recipe description

### Step 4 — Save Favorites

Click the ❤️ button to save your favorite recipes.

Favorites are stored using browser LocalStorage.

### Step 5 — Create a Meal Plan

Plan recipes for:

* Monday
* Tuesday
* Wednesday
* Thursday
* Friday
* Saturday
* Sunday

### Step 6 — Create Shopping List

Add missing ingredients directly to your shopping list.

The application stores important user data locally:

```text

smartchef-ingredients
smartchef-favorites
smartchef-shopping
smartchef-mealplan
```

This means your data remains available even after refreshing the browser.
